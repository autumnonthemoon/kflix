# Kflix

A movie streaming platform interface built with React and TypeScript. The project focuses on building a responsive, component-based interface and integrating TMDB API.

### Demo
View demo <a target="_blank" href="https://thuhang.nl/websitedemo/movie-app/">here</a>


## Features

* Browse movies and TV shows
* Search functionality
* Detailed movie/show information
* Responsive design for different screen sizes
* Ability to add favorites

## Tech Stack

* React
* TypeScript
* React Router
* SCSS
* Vite
* TMDB API

## Getting Started

### Installation

```bash
git clone <https://github.com/autumnonthemoon/kflix.git>
cd <kflix>
npm install
```

### Run the development server

```bash
npm run dev
```
